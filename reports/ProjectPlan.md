# Project Plan — CulinaryGraph

**Project name:** CulinaryGraph  
**Duration:** ~12 weeks  
**Approach:** Iterative (Agile-like mini sprints)

---

## 1.1 Phases & Timeline

| Phase | Duration | Description | Output |
|--------|-----------|-------------|--------|
| Requirements & Analysis | Week 1–2 | Functional & non-functional requirements | SRS Document |
| System Design | Week 3–4 | Architecture + UI/UX (Balsamiq) | Design docs + wireframes |
| Implementation | Week 5–9 | Backend + frontend development | Working features |
| Testing | Week 10–11 | Functional & usability testing | Test results |
| Deployment & Finalization | Week 12 | Final fixes + submission | Final product |

---

## 1.2 Iteration Plan (Sprint Breakdown)

| Sprint | Scope |
|--------|--------|
| Sprint 1 | Auth (login/register), homepage |
| Sprint 2 | Technique CRUD |
| Sprint 3 | Ingredient CRUD |
| Sprint 4 | Recipe CRUD |
| Sprint 5 | Knowledge map + relationships |
| Sprint 6 | Testing + improvements |

---

## 1.3 Milestones

- **M1:** Requirements approved  
- **M2:** Design completed  
- **M3:** Core features implemented  
- **M4:** Knowledge map ready  
- **M5:** Final submission

## 2. Communication Plan

### 2.1 Stakeholders

- Project owner  
- Instructor  
- Peer reviewers / classmates  

### 2.2 Communication Matrix

| Communication type | Frequency | Medium | Audience | Purpose |
|--------------------|-----------|--------|----------|---------|
| Weekly progress update | Weekly | Email / docs / class | Instructor | Share progress & blockers |
| Design review | Once (design phase) | Class / document | Instructor | Validate UI/UX |
| Milestone review | At each milestone | Class | Instructor | Approval |
| Issue tracking | Continuous | Notes / GitHub | Self | Track bugs/tasks |

### 2.3 Tools

- **Documentation** → PDF  
- **Design** → Balsamiq  
- **Development** → GitHub  
- **Communication** → Email / in class
